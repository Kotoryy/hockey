# Матч-центр КХЛ — сайт hockey.kotoryy.ru

Веб-версия Матч-центра, устроена по образцу spartak.kotoryy.ru. Сайт можно установить на телефон
(«Поделиться → На экран „Домой“» на iPhone, «Установить приложение» на Android), и он работает без сети
с последними загруженными данными.

Вкладки те же, что в программе для компьютера: Матч, Новости, Составы, Таблица, Календарь.
Есть светлая и тёмная тема (кнопка ◐). Кнопка «Команды» открывает любой матч КХЛ, а ссылка на него
сохраняется в адресе: `hockey.kotoryy.ru/#spartak--ska`. Без адреса открывается матч из `collector/config.json`.

## Как устроено

| Папка | Что это |
|---|---|
| `docs/` | Сам сайт: `index.html`, `app.js`, `styles.css`, `sw.js` (офлайн), `manifest.webmanifest`, `CNAME`. GitHub Pages публикует эту папку |
| `collector/` | Сборщик данных (Node.js без зависимостей): таблица, календари, составы и статистика всех 22 клубов с Sports.ru, новости из RSS и Google Новостей |
| `.github/workflows/collect.yml` | Каждые 20 минут запускает сборщик и кладёт результат в ветку `data` — это зеркало данных |

Сайт читает данные из `https://raw.githubusercontent.com/Kotoryy/hockey/data/` (так же, как Спартак читает `spartak-data`).
В ветке `data` всегда один коммит, поэтому репозиторий не разрастается.

## Публикация (один раз)

1. На GitHub создайте **публичный** репозиторий `Kotoryy/hockey`. Если назовёте иначе, поменяйте адрес
   в строке `const DATA = …` в `docs/app.js`.
2. Отправьте туда содержимое этой папки (ветка `main`).
3. **Settings → Pages**: Source — *Deploy from a branch*, ветка `main`, папка `/docs`.
   В поле *Custom domain* должно стоять `hockey.kotoryy.ru`, после выпуска сертификата включите *Enforce HTTPS*.
   Запись в Cloudflare уже есть: CNAME `hockey` → `kotoryy.github.io`, без проксирования.
4. **Actions → «Сбор данных» → Run workflow** — первый сбор, не дожидаясь расписания. Через минуту-две
   появится ветка `data`, и сайт оживёт.
5. Откройте лог этого запуска: в конце сборщик пишет, сколько клубов и новостей собрал и что не удалось.
   Если Sports.ru не отвечает серверам GitHub, там будет ошибка про таблицу.

GitHub выключает расписание, если в репозитории 60 дней не было коммитов. Тогда в Actions появится кнопка,
которая включает его обратно.

## Локально

```bash
cd "Матч-центр/Веб"
export PATH="$HOME/.local/node/bin:$PATH"
npm run collect   # данные в .local-data/ (около минуты)
npm run serve     # http://localhost:8080 — сайт берёт данные из .local-data
```

Если Sports.ru поменяет вёрстку, чинить нужно `collector/sources.js`. Тот же разбор страниц используется
в программе для компьютера: `Исходный код/src/sources.js`.
